# 📸 SnapVault

A fully responsive, customizable photo gallery and sharing web application built with native HTML, CSS, and JavaScript.

## ✨ Features

- **Photo Gallery & Grid Layouts:** Switch between standard grid view and responsive dynamic masonry layouts.
- **Customization Studio:** Customize themes (Dark/Light mode), dynamic color accents, fonts, and card border styles.
- **Photo Editor:** Adjust brightness, contrast, saturation, and apply built-in color presets using HTML5 Canvas.
- **Sharing Capabilities:** Direct URL parameters and instant QR Code generation for individual photos.
- **Local Persistence:** Data saved to browser `localStorage`.

## 🚀 Live Demo on GitHub Pages

1. Go to your repository settings on GitHub (`Settings` -> `Pages`).
2. Select `main` (or `master`) branch as the source.
3. Save and your site will be live at `https://yourusername.github.io/snapvault/`.
